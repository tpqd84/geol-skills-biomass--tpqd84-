# Research Methods — Your Personal Repo

This is your personal repository for the Research Methods module.
You'll use it to save your work each week and build up a portfolio of
code and analysis over the course.

## What's here

```
├── data/                    # Biomass mini-project datasets
│   ├── uk_electricity.csv   # UK electricity generation by fuel, 2000–2024
│   ├── pellet_imports.csv   # UK wood pellet imports by country of origin
│   ├── emission_factors.csv # CO₂ emission factors under different assumptions
│   └── README.md            # Data dictionary
├── week1.R                  # Starter file for Week 1
└── README.md                # This file
```

## How to use this repo

1. **Clone** this repo using GitHub Desktop (you should have done this
   already — if not, see the
   [pre-term preparation guide](https://geol-skills.github.io/materials/preparation.html)).

2. **Each week**, create a new `.R` file (e.g. `week2.R`, `week3.R`)
   and paste in the code you've written during the session. You can
   also copy code from the WebR exercises on the course site.

3. **Commit and push** at the end of every session:
   - In GitHub Desktop, you'll see your changed files listed.
   - Write a commit message that describes what you did — not just
     "week 2". For example: "Plot biomass vs coal generation over time"
     or "Add scenario analysis for transport emissions".
   - Click **Commit to main**, then **Push origin**.

4. **Weeks 3–4**: you'll write your policy briefing in this repo, in
   Markdown, as `briefing.md`, with its figures in `figures/`. You set
   the file up in Week 3 and write it in Week 4; your classmates then
   review it via GitHub Issues.

## Weekly checklist

- [ ] Week 1: `week1.R` — data exploration and first plots
- [ ] Week 2: `week2.R` — ggplot2 figures for the biomass case
- [ ] Week 3: `week3.R` — scenario analysis (changing the assumptions);
      `figures/` and a `briefing.md` skeleton
- [ ] Week 4: `briefing.md` — your policy briefing
